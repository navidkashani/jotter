A note-taking method built by the sociologist [[Niklas Luhmann]], who published
some seventy books from a wooden box of index cards.

## How it works

Every idea gets its own card. Every card gets a number that places it *next to*
a related card rather than in a category. New cards are inserted between
existing ones, so the box grows by branching instead of by filing.

The numbering is the whole trick: it makes the structure emergent. You never
decide up front what the categories are, because you never need to.

## Why it survives

Because it scales in the one direction that matters. A folder hierarchy gets
worse as it grows — every new note forces a decision about where it belongs. A
slipbox gets *better*, because every new note is another possible connection
for the notes already there.

This is the same reason [[Atomic notes]] matter: a card holding one idea can be
linked from anywhere. A card holding six can only be linked as a lump.
